## For team members (no coding required)

### Viewing the guide
Just click the live-site link above. It works on desktop, tablet, and phone — no login needed.

### Requesting a change
If you spot an error, want to update a statistic, or have a suggestion:

1. Go to the **[Issues](../../issues)** tab at the top of this page.
2. Click the green **New Issue** button.
3. Give it a short title (e.g., "Update the $400 figure on p. 20").
4. Describe what needs to change and click **Submit new issue**.

That's it — the person maintaining the code will pick it up from there.

## For the maintainer

### What's in this repo

```
index.html    ← the entire guide (one page)
styles.css    ← all styling (no JavaScript, no build step)
README.md     ← this file
```

### How to edit
1. Open the file on GitHub and click the ✏️ pencil icon, **or** clone the repo and edit locally.
2. Commit your changes to a new branch and open a Pull Request.
3. Once merged to `main`, GitHub Pages will redeploy automatically (usually within 1–2 minutes).

### Publishing setup (one-time)
1. Go to **Settings → Pages**.
2. Under "Source," select **Deploy from a branch**.
3. Set branch to **main**, folder to **/ (root)**.
4. Click **Save**.

### Optional: custom domain
If One Family owns a domain, you can point a subdomain (e.g., `evidence.onefamily.org`) to this site for free. Add a `CNAME` file to the repo containing the subdomain, then create a CNAME DNS record pointing to `YOUR-USERNAME.github.io`. GitHub's docs: [Configuring a custom domain](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
